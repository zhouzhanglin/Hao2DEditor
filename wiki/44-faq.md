# 44 常见问题

[← 返回目录](index.md) ｜ 上一篇：[43 快捷键速查](43-shortcuts.md)

> 先看状态栏提示 —— 编辑器把绝大多数失败原因都写在那里了（见 [12 状态栏与提示](12-statusbar.md)）。

---

## 一、显示与渲染

**角色在视口里是白块**

看状态栏「纹理 x/y」：

- `x < y` 说明有图没加载出来。常见原因：图片被移动/改名、文件损坏、工程从别处拷来但没带上 `images/`。
- 处理：重新导入该图，或用资源面板右键「替换图片…」保持原图名。

**骨骼骨架看不见了**

视口右上角的「骨骼」开关被关了。关掉时骨骼**也点不中**，一并恢复。

**约束手柄不见 / IK 没反应**

1. 「约束」开关是否打开；
2. 属性面板里约束的「启用」是否打开；
3. 「目标」和「受约束骨骼链」是否都设置了（为空时面板会直接警告）。

**参考图挡住角色**

降低舞台参考图的透明度（默认 0.5），或「删除图片」。

## 二、状态与模式

**按 `K` / `空格` 没反应**

当前是 Pose 态。按 `Tab` 切到 Animate，并确认时间轴上选了一个动画。

**右栏属性面板不见了**

Animate 态整栏收起，按 `Tab` 回 Pose。

**「资源与皮肤」变成了「曲线」**

同上，Animate 态左栏第三块固定是曲线面板。

**工具面板少了几个按钮**

Animate 态只保留「选择」和「FFD 顶点工具」；画骨骼 / 权重刷 / Pose / 遮罩只在 Pose 态可用。

**改不了骨骼父级 / 插槽层级**

Animate 态禁止改绑定数据，状态栏会提示「切到 Pose 状态才能改绑定数据」。

---

## 三、绑定与蒙皮

**转动骨骼，贴图不跟着变形**

- 插槽宿主错了 → 层级树里检查插槽挂在哪根骨骼下；
- 或者你用的是选择工具拖骨骼（网格被锁在世界坐标），想让网格跟着走请用 [Pose 工具](21-tool-pose.md)。

**拖顶点后贴图糊了 / 跑了**

Pose 工具拖顶点**不重算 UV**（贴图会跟着顶点走）。想保持贴图原地，用 [网格工具 M](24-tool-mesh.md)。

**关节处撕裂**

权重过渡太硬。用权重刷的 `Ctrl`（平滑）在过渡带刷几下；或者先在「权重骨骼列表」里补全骨骼再「自动计算权重」。

**权重刷没反应**

按顺序检查：

1. 是否在 Pose 态；
2. 是否选中了**网格附件**（Region 要先转网格）；
3. 是否确定了目标骨骼（层级树点一根，或属性面板 Bone 下拉）；
4. 笔刷 `Hardness` 是否太低（默认 1.5，很轻）。

**点了一下空白处，顶点选择没被清掉**

这是新交互：网格 / FFD 工具的**左键拖框 = 框选顶点**，单击（不足 3px）不再清空选择。想取消选择请按**右键**，或点层级树其它节点。

**框选不到别的部件的顶点**

框选只收**当前选中附件**的顶点（网格工具本来就把其它部件隔离显示）。先选中目标网格附件再框。

**多选顶点后按 Delete 只删掉一个**

当前 `Delete` 只删选择列表里的第一个顶点。批量删只能逐个来。

**「自己绘制边界」把我之前的网格弄没了**

它是整块重画，会丢弃原点、权重与 FFD 关键帧（进去前有确认框）。按 `⌘Z` / `Ctrl+Z` 整步撤销。

## 四、动画

**打了关键帧但动画不动**

- 关键帧是否打在**要动的通道**上（例如只打了「位置」却去转骨骼）；
- 时间轴是否选对了动画；
- 播放头是否落在关键帧区间内。

**循环播放时首尾跳一下**

最后一帧要复制第一帧的姿态（`⌘C` / `⌘V`），并给两端都套「缓入缓出」。

**换装动画出现「渐变叠影」**

显示帧的缓动必须是「阶跃」，否则两张图会混合过渡。

**子骨架不动 / 一直停着**

1. 属性面板里「默认动画」是否是 `（setup 姿态）`；
2. 时间轴上有没有「子骨架」通道的关键帧；
3. 「引用骨架」是否被断开（显示 `（未引用）`）。

详见 [14 子骨架](14-subarmature.md)。

**时间轴找不到「子骨架」轨道**

只有插槽里挂了骨架 display、**并且打过帧**之后才会出现。先在属性打帧条或该插槽的 ⚡ 处打一帧。

**FFD 越拖越夸张**

同一时间点重复拖会**累加**偏移，撤销后重新拖，或换到别的时点。

## 五、导入

**提示「请先保存或创建工程」**

PSD / 单图导入要把文件写进工程目录的 `images/`，所以必须先有工程文件。

**Spine 导入失败**

- json 里必须有 `skeleton` 段；
- 同目录必须有 `.atlas` 与图集 png；
- 混合模式 `mask` 会被降级为 Normal 并告警。

**DragonBones 导入失败**

- 骨骼 json 里要有 `armature` 段；
- 同目录要有 `texture_*.json` 与图集 png；
- 不支持内嵌 `armature` 类型的显示对象。

**导入后原来的内容没了**

只有 Spine / DragonBones 会问，且默认是「创建新工程」= **整份替换**。导入前先保存，或在弹窗里选「导入当前工程」把新内容追加成新骨架。

**弹出「请选择这份资源要导入到哪里」**

正常流程（仅 Spine / DragonBones）。选「创建新工程」或「导入当前工程」，`Esc` 取消。见 [13 对话框合集](13-dialogs.md)。

**拖入文件夹没反应**

文件夹里没有支持的图片扩展名（png / jpg / jpeg / webp / gif / bmp）。

## 六、导出

**「未被打包」警告**

有图超过了「单页最大」的边长。调大单页尺寸，或把过大的图拆小。

**Unity 里材质变 Missing**

png 与 `<纹理基名>_Hao2D.mat` 必须**同目录**；不要把文件挪到子文件夹里。

**Spine 导出后角色身上的武器 / 挂件不见了**

Spine 不支持骨架嵌套，子骨架 display 会被跳过。把武器并进同一个骨架再导。

**Spine 打开后显示异常**

确认用 Spine 4.3 打开；旧版不支持 4.2+ 的约束与贝塞尔坐标格式。

**导出目录里只有一个空文件夹**

检查弹窗底部提示，通常是没勾选骨架，或图集全部超限未打包。

**重复导出后 Unity 引用丢了**

正常情况下 GUID 是稳定的；如果曾手动删除 `.meta`，重新导出会生成新 GUID，需要重新关联。

---

## 七、工程与文件

**换了台电脑，图全丢了**

要把**整个工程文件夹**一起拷走（`xxx.hao2d.proj` + `images/` + `stage/`），只拷工程文件是不够的。

**工程打不开**

- 确认后缀是 `.hao2d.proj`（也认 `.json`、`.hao2dproj`）；
- 工程是 JSON，可以用文本编辑器打开看是否被截断；
- 若提示版本相关错误，用更新版本打开。

**想手工改工程文件**

可以，它是可读 JSON。但改之前务必备份 —— 结构不对会导致打不开或数据丢失。

---

## 八、AI 接入

**面板显示「命令服务未启动」**

浏览器调试模式没有服务，请用桌面版。

**客户端连不上 / 工具列表为空**

1. 先 `GET /health` 探活；
2. 复制完整的 MCP 地址（含 token）；
3. 重启 AI 客户端。

**分享工程时担心泄露**

工程目录里的 `ai/hao2d-ai-server.json` 含访问 token，分享前删掉 `ai/` 目录。

---

## 九、还是解决不了

1. 看状态栏的完整提示（它会说明具体哪个对象、哪个文件）；
2. 用「视图 → 开发者工具」看控制台日志（日志前缀统一是 `[hao2d]`）；
3. 把「操作步骤 + 状态栏提示 + 工程文件」一起反馈，最容易定位。
