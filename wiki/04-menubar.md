# 04 菜单栏

[← 返回目录](index.md) ｜ 上一篇：[03 工程与骨架管理](03-project.md) ｜ 下一篇：[05 层级结构](05-hierarchy.md)

> 一句话：菜单栏负责「文件级操作」，并把当前状态（项目名、是否改过、Pose/Animate）一路显示在中间和右端。

![菜单栏](assets/panel-menubar.png)

---

## 一、左侧：快捷动作

| 按钮 | 作用 | 快捷键 |
| :--- | :--- | :--- |
| **新建项目** | 打开「新建项目」弹窗（项目名 / 保存位置 / 帧率） | `⌘N` / `Ctrl+N` |
| **打开** | 打开 `.hao2d.proj` 工程（也认 `.json`、`.hao2dproj`） | `⌘O` / `Ctrl+O` |
| **保存** | 保存到当前路径；没保存过会先问路径 | `⌘S` / `Ctrl+S` |
| **导入图片** | 选碎图 / 图集 png / 文件夹；选到 `.psd` 会走 PSD 导入 | `⌘I` / `Ctrl+I` |
| **导出 ⌄** | 下拉三项：导出运行时 / 导出 Unity / 导出 Spine | 见下表 |
| **最近打开的工程**（时钟图标） | 下拉最近打开过的工程路径，点击直接打开 | — |
| **撤销 / 重做** | 撤销一步 / 重做一步 | `⌘Z` `⇧⌘Z` / `Ctrl+Z` `Ctrl+Shift+Z` |

> 长按或悬停按钮都能看到完整提示，例如「导入或拖入碎图 / PSD (Ctrl+I)」。

### 导出下拉

| 菜单项 | 产物 | 快捷键 |
| :--- | :--- | :--- |
| **导出运行时** | `<名称>_ske.json` + `<名称>_atlas.json` + 图集 png | `⌘E` / `Ctrl+E` |
| **导出 Unity** | `<骨架>.hao2d` + 图集 png + 材质 | `⇧⌘E` / `Ctrl+Shift+E` |
| **导出 Spine** | Spine 4.3 的 `<名称>.json` + `<名称>.atlas` + 图集 png | `⌥⌘E` / `Ctrl+Alt+E` |

三项都会先弹出导出对话框（选目录、调图集参数、看预览），细节见 [41 导出详解](41-export-formats.md)。

## 二、中间：项目信息

| 显示项 | 说明 |
| :--- | :--- |
| 项目名 | 新建时填的名字，也是导出时的图集名与目录名 |
| 橙色圆点 | 有未保存修改（窗口标题同样会带 `*`） |
| 工程路径 | 完整路径，超长会截断，鼠标悬停可看全 |

---

## 三、右侧：状态与布局

| 元素 | 说明 |
| :--- | :--- |
| **状态徽标** | Pose 态显示「准备」，Animate 态显示「动画」。这只是显示，切换按钮在视口左上角（或按 `Tab`） |
| **重置面板布局** `⌄` | 把所有面板恢复到默认尺寸，包括左栏内各面板记住的高度 |

## 四、原生菜单（Windows / macOS 顶部菜单）

菜单栏按钮之外，桌面版还有系统菜单，常用项如下：

**文件**

新建项目、打开、保存、另存为；导入 Spine、导入 DragonBones、导入图片、导入 PSD；导出运行时、导出 Unity、导出 Spine；设置、AI 接入；关闭窗口 / 退出。

**编辑**

撤销、重做；复制、粘贴、复制生成（`⌘D`）；剪切、全选；删除（`Delete`）。

> 复制 / 粘贴是「上下文相关」的：焦点在输入框里时走文本复制粘贴；否则复制 / 粘贴层级节点或关键帧。

**动画**

播放 / 暂停（`空格`）、上一帧（`←`）、下一帧（`→`）、给选中对象打关键帧（`K`）。

**视图**

适配视野（`F`）、重置面板布局；重载、开发者工具；实际大小、放大、缩小。

> 「动画」菜单里的播放与打帧**只在 Animate 态有意义**，在 Pose 态点击会提示先按 `Tab` 切换。

## 五、相关快捷键

完整列表见 [43 快捷键速查](43-shortcuts.md)。菜单栏最常用的几个：

- `⌘S` 保存、`⌘⇧S` 另存为、`⌘O` 打开、`⌘I` 导入图片
- `⌘Z` / `⇧⌘Z` 撤销 / 重做
- `Tab` 切 Pose / Animate
