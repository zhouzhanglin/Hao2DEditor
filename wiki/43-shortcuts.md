# 43 快捷键速查

[← 返回目录](index.md) ｜ 上一篇：[42 AI 接入](42-ai.md) ｜ 下一篇：[44 常见问题](44-faq.md)

> 规则：焦点在输入框 / 文本域 / 可编辑区域时，**所有单键快捷键都会被跳过**，可以正常打字。

---

## 一、文件与工程

| 功能 | macOS | Windows / Linux |
| :--- | :--- | :--- |
| 新建项目 | `⌘N` | `Ctrl+N` |
| 打开工程 | `⌘O` | `Ctrl+O` |
| 保存 | `⌘S` | `Ctrl+S` |
| 另存为 | `⇧⌘S` | `Ctrl+Shift+S` |
| 导入图片 | `⌘I` | `Ctrl+I` |
| 导出运行时 | `⌘E` | `Ctrl+E` |
| 导出 Unity | `⇧⌘E` | `Ctrl+Shift+E` |
| 导出 Spine | `⌥⌘E` | `Ctrl+Alt+E` |
| 全局设置 | `⌘,` | `Ctrl+,` |

---

## 二、编辑

| 功能 | macOS | Windows / Linux | 说明 |
| :--- | :--- | :--- | :--- |
| 撤销 | `⌘Z` | `Ctrl+Z` | 「自己绘制边界」/ 画遮罩过程中只撤最后一个点 |
| 重做 | `⇧⌘Z` | `Ctrl+Shift+Z` | — |
| 复制 | `⌘C` | `Ctrl+C` | 焦点在输入框时走文本复制 |
| 粘贴 | `⌘V` | `Ctrl+V` | Animate 态粘贴关键帧到播放头 |
| 就地复制 | `⌘D` | `Ctrl+D` | Animate 态粘贴到最后一帧之后 |
| 剪切 | `⌘X` | `Ctrl+X` | 标准文本编辑角色 |
| 全选 | `⌘A` | `Ctrl+A` | 视口里 = 选中全部骨骼 |
| 删除 | `Delete` / `Backspace` | 同左 | 优先级：网格顶点 → 遮罩控制点 → 关键帧 → 整条通道；顶点多选时**只删第一个** |

## 三、模式与视图

| 功能 | 键 | 限制 |
| :--- | :--- | :--- |
| 切换 Pose ↔ Animate | `Tab` | 始终可用 |
| 适配视野 | `F` | — |
| 重置面板布局 | 无快捷键（菜单项） | — |

## 四、工具（单键，无需组合）

| 键 | 工具 | 可用状态 |
| :---: | :--- | :--- |
| `V` | 选择 | Pose + Animate |
| `P` | Pose | 仅 Pose |
| `B` | 画骨骼 | 仅 Pose |
| `M` | 网格工具 | 仅 Pose |
| `D` | FFD 顶点工具 | Pose + Animate（Pose 态同一工具叫网格工具） |
| `G` | 权重刷 | 仅 Pose |
| `N` | 遮罩 | 仅 Pose |

> `M` 与 `D` 是同一个工具的两种身份：Pose 态叫网格工具，Animate 态叫 FFD 顶点工具。

## 五、骨骼变换坐标系

| 键 | 模式 |
| :---: | :--- |
| `W` | 移动 |
| `E` | 旋转 |
| `R` | 缩放 |
| `T` | 斜切 |

在绘制类工具（权重刷 / FFD / 遮罩）下按这些键，会自动**退出绘制工具**并切回带变换的鼠标。

---

## 六、动画（仅 Animate 态）

| 功能 | 键 | 说明 |
| :--- | :--- | :--- |
| 播放 / 暂停 | `空格` | 未选动画时会自动选第一个并开播 |
| 上一帧 | `←` | — |
| 下一帧 | `→` | — |
| 打关键帧 | `K` | 优先只打时间轴上点中的通道（选中「子骨架」子轨时只打子骨架帧） |
| 删除关键帧 | `Delete` | 只选了通道时删整条通道 |

在 Pose 态按这些键：

- `空格` → 「播放控制仅在 Animate 状态可用（Tab 切换）」
- `K` → 「打关键帧只在 Animate 状态可用（Tab 切换）」
- `←` `→` → 无响应

## 七、其他

| 功能 | 键 | 说明 |
| :--- | :--- | :--- |
| 结束「绑定骨骼」状态 | `Esc` | 只在刷权重等骨骼拾取时有效 |
| 关闭弹窗 | `Esc` | 除确认框外都支持 |
| 清空层级树搜索 | `Esc` | 焦点在搜索框时 |
| 取消遮罩绘制 | `Esc` | 遮罩工具下 |
| 平移视口 | **中键拖动** | 没有键盘平移，`空格` 是播放 |
| 缩放视口 | **滚轮** | 以鼠标位置为锚点 |

## 八、鼠标操作速查

| 操作 | 效果 |
| :--- | :--- |
| 左键单击 | 选中 |
| `Shift` / `⌘` / `Ctrl` + 左键 | 加选 / 减选（骨骼、图片、关键帧通用） |
| 左键拖动 | 按当前工具处理 |
| 左键拖框（网格 / FFD 工具） | **框选顶点**；`Shift` 拖框 = 加进当前选择 |
| 中键拖动 | 平移视口 |
| 滚轮 | 缩放视口 |
| 右键（网格 / FFD 的编辑顶点） | **取消选择** |
| 右键（选择 / Pose 工具，点在图片上） | 插槽层级菜单 |
| 右键（遮罩） | 闭合多边形 |
| 右键（自己绘制边界 / 自定义布线） | 闭合边界 / 取消连线 |
| 右键（待绑定骨骼状态） | 结束绑定 |
| 双击空白 | 适配视野 |
| 双击层级树节点 | 聚焦该对象 |
| `Alt` + 点击网格内部 | 插入顶点（网格 / FFD 工具） |
| `Alt` + 点击遮罩点 | 删除该控制点 |
| `Alt` + 刷权重 | 减少权重 |
| `Shift` + 刷权重 | 覆盖权重 |
| `Ctrl` + 刷权重 | 平滑权重 |
