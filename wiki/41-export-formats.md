# 41 导出详解

[← 返回目录](index.md) ｜ 上一篇：[40 导入详解](40-import-formats.md) ｜ 下一篇：[42 AI 接入](42-ai.md)

> 一句话：三种导出共用一个弹窗，差别在**产物格式**与**命名规则**。

| 模式 | 快捷键 | 一句话 |
| :--- | :--- | :--- |
| **运行时** | `⌘E` / `Ctrl+E` | 自研 `.hao2d` 生态用的 ske + atlas + png |
| **Unity** | `⇧⌘E` / `Ctrl+Shift+E` | Unity 里用 Hao2D 导入器：`.hao2d` + png + 材质 |
| **Spine** | `⌥⌘E` / `Ctrl+Alt+E` | 导出 Spine 4.3 工程，可继续在 Spine 里编辑 |

---

## 一、共用参数

| 控件 | 默认 | 说明 |
| :--- | :--- | :--- |
| **导出目录** | 上次的选择 | 编辑器会在里面新建子文件夹；记在本机，下次沿用 |
| **导出骨架** | 全选 | 每个骨架一份产物；至少勾一个；有「全选 / 仅当前」 |
| **图集范围** | 所有骨架用到的图 | 或「只含选中骨架用到的图」 |
| **图集缩放** | 工程里记的值，否则 100% | 0.1–1，步长 0.05；预设 25 / 50 / 75 / 100% |
| **单页最大** | 2048 | 1024 / 2048 / 4096 |
| **图集预览** | — | 每页打包结果，显示页数、尺寸、碎图数；可翻页 |
| **预览（在线）** | — | 仅运行时 / Spine 模式且桌面版可用：起本地服务，用 Spine 官方运行时播放，支持手机扫码 |
| **atlas名追加 .txt** | 关 | 仅 Spine 模式显示，写入全局设置 |

> 「图集缩放」只改变**纹理分辨率**，不改变角色在游戏里的大小。所有页都是「原图整页复制」时该控件会隐藏。

导出完成后，如果工程已有保存路径，编辑器会把本次缩放写回工程并自动保存。

---

## 二、运行时（runtime）

**输出目录**：`<所选目录>/<项目名>/`

| 文件 | 规则 |
| :--- | :--- |
| `<骨架名>_ske.json` | 每个勾选的骨架一份；文件名清洗，重名加 `_2` |
| `<项目名>_atlas.json` | 图集只有一份，名字跟**项目名** |
| `<项目名>_0.png`… | 图集页，页名跟**项目名**编号 |

- 坐标单位按运行时 PPU 序列化。
- 本来就是图集的页会**原样整页复制**（不重编码、不参与缩放）；碎图才重新打包。
- 超过单页最大边长的图会告警「未被打包」。
- 完成提示会列出产物路径，并自动在文件管理器里定位。

## 三、Unity（unity）

**输出目录**：`<所选目录>/<项目名>/`

```
<项目名>/<骨架名>.hao2d          + .meta   骨骼 / 动画（每个勾选骨架一份）
<项目名>/<项目名>_0.png          + .meta   图集页（meta 带 GUID 供材质引用）
<项目名>/<项目名>_0_Hao2D.mat    + .meta   材质：Shader Hao2D/Sprite，_MainTex 指向图集页
```

约定：

- `.hao2d` 由 Unity 端的 `Hao2DImporter`（ScriptedImporter）导入；
- 纹理按 `.hao2d` 内的 `textureNames` **在同目录**查找；
- 材质按 `<纹理基名>_Hao2D.mat` **同目录**查找；
- 纹理 meta 设为不裁剪、无 mipmap、Clamp + Bilinear、保留透明；
- **GUID 稳定**：同目录已有 `.meta` 就沿用，否则按「工程名/文件名」确定性生成 —— 重复导出不会让 Unity 里的引用变 Missing。

> 弹窗会提示 `.hao2d` 与 Unity 运行时的能力差异（例如变换 / 路径约束可能写不进去），这类提示会写明「N 条与 Unity 运行时的差异提示」。

## 四、Spine 4.3（spine）

**输出目录**：`<所选目录>/<骨架名>/`（注意：这里是**骨架名**，不是项目名）

| 文件 | 规则 |
| :--- | :--- |
| `<骨架名>.json` | Spine 4.3 骨骼 JSON |
| `<骨架名>.atlas` 或 `<骨架名>.atlas.txt` | 看「atlas名追加 .txt」或全局设置；文本使用 4.2+ 的 `bounds` / `offsets` 语法 |
| `<骨架名>_0.png`… | 图集页，页名跟**骨架名** |

- **Spine 模式只导一个骨架**（当前骨架）。
- 区域名如果形如 `xxx.png` 会被改名（否则 spine-unity 会当成新图集页），json 里的 `path` 同步改。
- DragonBones 导入的裁剪信息会反解成 `.atlas` 的 `offsets`。

---

## 五、多骨架命名对照

| 模式 | 输出目录 | 骨架文件 | 图集描述 | 图集页 |
| :--- | :--- | :--- | :--- | :--- |
| 运行时 | `<项目名>/` | `<骨架名>_ske.json` | `<项目名>_atlas.json` | `<项目名>_0.png`… |
| Unity | `<项目名>/` | `<骨架名>.hao2d` | 无（靠 `.hao2d` 内 textureNames） | `<项目名>_0.png` + `_Hao2D.mat` |
| Spine | `<骨架名>/` | `<骨架名>.json` | `<骨架名>.atlas[.txt]` | `<骨架名>_0.png`… |

命名兜底顺序：工程里记的项目名 → 工程文件名 → 当前骨架名；非法字符 `\/:*?"<>|` 替换成 `_`。

## 五·五、子骨架（骨架嵌套）的导出

| 模式 | 行为 |
| :--- | :--- |
| **运行时** | 被嵌套的骨架**一起导出**；ske 里写 nested 清单，运行时按骨架名加载 |
| **Unity** | 需要把被嵌套骨架的 `.hao2d` **一起导出到同一目录**；导入器按骨架名关联，缺文件时该 display 不渲染 |
| **Spine** | **不支持嵌套**，这些 display 会被跳过，提示里会写「已跳过这些 display」 |

导出弹窗的提示区会额外列出：

- 「包含嵌套子骨架：X（已一并导出）」
- 「骨架「A」引用了工程里不存在的骨架「B」」—— 引用断了，导出成空 display

> 所以 Spine 导出前，如果角色身上挂了武器 / 坐骑子骨架，需要先把它们并进同一个骨架，否则产物里会丢。

详见 [14 子骨架](14-subarmature.md)。

## 六、导出前后检查清单

**导出前**

- [ ] 状态栏纹理 x/y 相等
- [ ] 没有未处理的编译警告
- [ ] 工程已保存（标题栏无橙点）
- [ ] 动画名清晰、时长正确

**导出后**

- [ ] 产物文件齐全
- [ ] 图集 png 排布紧凑、无裁切
- [ ] 骨架 json 里动画数量与时间轴一致
- [ ] 用「预览」实际播一遍

## 七、常见问题

| 现象 | 处理 |
| :--- | :--- |
| 「至少要勾选一个骨架」 | 勾选至少一个 |
| 「未被打包」警告 | 单页最大调大，或拆分超尺寸的图 |
| Unity 里材质 Missing | png 与 `.mat` 必须在同一目录 |
| Spine 打开后层级混乱 | 检查是否用了旧版 Spine 打开 4.3 数据 |
| 想导出单个骨骼给程序 | 用「仅当前」只勾当前骨架 |
